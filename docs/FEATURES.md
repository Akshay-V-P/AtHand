# AtHand — Feature Inventory & Implementation Matrix

## 1. Feature Classification Legend

- **Fully Implemented**: Complete vertical stack from UI through API, use case, and database persistence.
- **Partially Implemented**: Working end-to-end with specific missing capabilities or edge case handlers.
- **Mocked / Hardcoded**: UI exists with synthetic or static data; no real backend integration.
- **Backend Only**: Fully defined API and use case without corresponding dedicated client UI.
- **Frontend Only**: UI views exist without backend persistence or backing endpoints.
- **Incomplete**: Placeholder or unfinished implementation in either frontend or backend.
